    💬 WhatsApp tips
      
      
      
      
      
      
      
      
    Keep web.whatsapp.com open in an Edge tab (WhatsApp set to English). Pin your tip groups in WhatsApp so they stay at the top of the chat list. The reader only reads; it never sends anything. Alerts use the channels set up below.
    
    
    
    
    Telegram (free, recommended)
      
      
      
      
    
      
    Setup: in Telegram search @BotFather → send /newbot → pick any name and a username ending in “bot” → copy the token it gives you into Bot token. Then open your new bot, tap Start, come back here and click Detect my chat ID.
    
    
    
    
    WhatsApp (free, via CallMeBot — can be unreliable)
      
      
      
      
    Setup: save +34 644 66 32 62 in contacts, send it “I allow callmebot to send me messages” on WhatsApp, and it replies with your API key.
    
    
    
    
    Email (free, via EmailJS)
      
      
      
      
      
      
      
    Create a free account at emailjs.com, connect Gmail as a service, make a template using {{subject}}, {{message}} and {{to_email}}, and turn on “Allow EmailJS API for non-browser applications” under Account → Security.
